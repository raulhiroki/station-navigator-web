# Station Navigator Web (ステーション・ナビゲーター Web版)

巨大駅・地下街（梅田・大阪駅、新宿駅）に特化した、屋内ナビゲーション Web アプリケーション (PWA) です。  
訪日外国人旅行者・出張者・観光客向けに、地下でも迷わずスムーズに目的地へ案内します。

🌐 **公開URL**: [https://raulhiroki.github.io/station-navigator-web/](https://raulhiroki.github.io/station-navigator-web/)

---

## 📱 主な機能

- **2Dフロア構内マップ**:
  - ピンチイン/アウトでの拡大・縮小、ドラッグ操作による構内図のスクロール
  - 階層切り替えバー（3F〜B2F）による立体的なフロアマップ表示
- **リアルタイム目的地・施設検索**:
  - 改札、出口番号（例:「5番出口」「中央口」）、多機能トイレ、コインロッカー、ランドマークのインクリメンタル検索
  - カテゴリフィルターチップ（改札 / 広場 / 施設 / 出口）
- **ルート案内＆ステップ更新**:
  - 鮮やかなシアンブルーの発光ルートライン描画
  - 地下街で電波が届かなくても安心の「手動ステップ位置更新」ナビゲーション
- **多言語対応（7言語）**:
  - 日本語 (ja)、英語 (en)、スペイン語 (es)、ポルトガル語 (pt)、フランス語 (fr)、ドイツ語 (de)、イタリア語 (it)
- **ルート共有機能**:
  - 現在選択中のルートを共有URLとして発行（未インストール相手でもブラウザで即座に開けます）
